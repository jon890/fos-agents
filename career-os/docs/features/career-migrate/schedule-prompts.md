# 예약 작업 지시문

운영이 커리어 에이전트에 등록할 예약 작업 둘의 지시문이다. 알림은 둘 다 「항상」 으로 둔다.
등록과 Hermes cron 삭제는 운영 저장소의 절차가 갖는다. 이 문서는 지시문의 원문만 갖는다.

실행 공간의 셸 설정이 `CLAUDE_PLUGIN_ROOT`, `CAREER_WORKSPACE_ROOT` 를 넘겨야 두 스킬이 설치된다(공고 추천은 `CAREER_EVIDENCE_DIR` 도).

## 공고 추천

```text
position-recommender 스킬로 오늘의 공고 추천을 한 번 실행한다.

- 스킬의 「시작 전: 맥락 문서」 부터 한다. 문서가 없으면 실행기를 부르지 않고, 답의 첫 줄에 어느 문서가 없는지 적는다.
- 실행기가 실패로 끝나면 답의 첫 줄에 실행기 표준 오류의 첫 줄을 그대로 적는다. 다른 방법으로 이어 가지 않는다.
- 끝까지 가면 `finalize` 의 `다음 단계:` 줄대로 리포트 사본을 「내 파일」 에 넣는다. 건너뛰지 않는다. 스킬의 「최종 답변」 형식으로 답하고 「내 파일」 줄(넣은 이름 또는 넣지 못한 이유)을 반드시 둔다.
- 순위에 든 공고가 없고 실패와 수집 경고도 없으면 답 전체를 [SILENT] 로 끝낸다.
- 설정(분석 정책, 회사 선호, 제외 규칙)은 이 실행에서 바꾸지 않는다.
```

## 공부 추천

```text
study-collection 스킬로 오늘의 공부 추천을 한 번 실행한다.

- 스킬의 「1. 맥락 문서와 점검」 부터 한다. 문서가 없으면 실행기를 부르지 않고, 답의 첫 줄에 learning-interests 문서가 없다고 적는다.
- 점검(`study --doctor`)이 실패하면 수집하지 않고, 답의 첫 줄에 실패한 항목을 적는다. 켜진 소스가 없으면(`sources`) `study-sources add` 로 소스를 먼저 넣어야 한다고 적는다. 이때는 [SILENT] 로 끝내지 않는다.
- 수집, 후보 준비, 선택, 리포트, 추천 저장 순서로 한다. 공유 링크는 만들지 않는다.
- 실행기가 실패로 끝나면 답의 첫 줄에 실행기 표준 오류의 첫 줄을 그대로 적는다.
- 오늘 추천이 이미 저장돼 있으면(같은 날의 두 번째 저장은 충돌로 끝난다) 다시 저장하지 않고 답 전체를 [SILENT] 로 끝낸다.
- 고른 자료가 없고 실패도 없으면 답 전체를 [SILENT] 로 끝낸다.
- 끝까지 가면 `reportCopy` 의 리포트 사본을 「내 파일」 에 넣는다(건너뛰지 않는다). 「내 파일」 줄(넣은 이름 또는 넣지 못한 이유)과 고른 주제와 자료 수를 알린 뒤 실행 폴더를 정리한다.
```
