## ADR-097 — 일반 질문은 public, 개인 질문은 private에 둔다

- Status: Accepted
- Date: 2026-06-17

### 맥락

공개 가능한 일반 면접 질문과 개인 이력을 반영한 질문을 같은 저장소에 두면 공개 경계가 흐려진다.
드릴이 별도 질문 풀을 관리하면 공개 question bank와 내용이 중복된다.

### 결정

- 공개 가능한 backend/CS 질문의 정본은 `public/question-bank/`에 둔다.
- 기술·인성 드릴은 같은 공개 question bank에서 질문을 읽는다.
- 개인 이력, 특정 회사, 특정 공고를 반영한 질문은 `private/`에 둔다.
- 질문과 약점 상태는 공통 `topic` 식별자로 연결한다.
- question-bank collector는 공개 가능성과 중복을 검증한 뒤 public 정본을 갱신한다.

### 거절한 대안

- 드릴용 질문 풀을 따로 두면 중복과 스키마 drift가 생긴다.
- 개인 맞춤 질문을 public에 두면 개인 맥락이 누출된다.

### 결과

일반 질문은 공개 자산으로 재사용하고 개인 질문은 비공개 경계 안에 유지한다.
