## ADR-027 — 면접 핏 진단을 통합하고 토픽 설정을 책임별로 나눈다

- Status: Partially superseded by [[ADR-092]]
- Date: 2026-05-15

### 맥락

면접 핏 진단의 baseline과 daily 모드는 범위만 다르고 코드가 대부분 중복됐다.
모든 토픽 설정을 한 JSON에 두는 구조도 각 skill이 필요한 부분만 읽기 어려웠다.

### 결정

- 중복된 핏 진단은 하나의 skill로 통합한다.
- 토픽 설정은 사용 책임별 JSON으로 분리한다.
- 단순 실행 확인용 모드는 제거하고 실제 사용 흐름을 검증한다.

### 거절한 대안

- 유사한 진단 skill을 둘로 유지하면 분기와 판정 기준이 다시 갈라진다.
- 대형 토픽 JSON을 유지하면 편집과 선택적 로드 비용이 계속 커진다.

### 결과

진단 책임과 토픽 설정의 소유권이 분명해졌다.
답변 성능 기반 약점 환류는 [[ADR-092]]가 대체한다.
