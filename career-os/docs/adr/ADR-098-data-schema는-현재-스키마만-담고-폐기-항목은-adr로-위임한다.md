## ADR-098 — data-schema는 현재 스키마만 담는다

- Status: Accepted
- Date: 2026-06-17

### 맥락

이미 폐기한 경로와 스키마를 `docs/data-schema.md`에 보존하면 새 구현이 엇 계약을 따를 수 있다.
스키마 문서는 이력서가 아니라 현재 구현 계약이어야 한다.

### 결정

- `docs/data-schema.md`에는 현재 코드가 생성하거나 소비하는 스키마만 둔다.
- 폐기한 필드, 경로, 데이터 모델은 ADR 또는 Git 이력으로 추적한다.
- 코드가 아직 참조하는 계약은 legacy라도 제거 전까지 문서화한다.
- 문서와 코드가 다르면 코드 사용처를 확인한 뒤 둘을 함께 고친다.

### 거절한 대안

- 폐기 항목을 별도 장에 모으면 현재 계약과 오래된 계약의 경계가 다시 흐려진다.

### 결과

스키마 문서를 읽는 사람과 에이전트는 현재 구현에 필요한 계약만 본다.
