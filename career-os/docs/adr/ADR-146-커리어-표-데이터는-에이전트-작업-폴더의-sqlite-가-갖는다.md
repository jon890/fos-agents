## ADR-146: 커리어 표 데이터는 에이전트 작업 폴더의 SQLite 가 갖는다

- **status**: `accepted`
- **결정**:
  - **공고, 회사, 공부, 면접처럼 줄이 많은 커리어 데이터는 커리어 에이전트 주인의 작업 폴더에 있는 SQLite 파일 하나(`state/career.sqlite`)가 갖는다.** 커리어 Backend 와 그 MySQL 은 내린다(사용자 결정 2026-11-21, 원본 스펙은 fos-assistant `docs/features/career-migrate/spec.md` 의 DECISION3).
  - **규칙을 지키는 코드는 `scripts/lib/career-store/` 다.** Backend 의 HTTP 경로 하나가 저장 모듈의 함수 하나이고 입력과 출력이 같다. 실행기만 이 모듈을 부른다. 새 서비스를 만들지 않는다.
  - **저장은 `bun:sqlite` 로 하고 의존성을 더하지 않는다.** 스키마 버전은 SQLite `user_version` 으로 관리하고 실행기가 열 때 모자란 단계만 적용한다.
  - **쓰기는 `BEGIN IMMEDIATE` 로 파일을 잠근다.** 잠금을 5초 안에 얻지 못하면 `CAREER_STORE_BUSY` 로 끝내고 다음 실행이 이어 간다. 여러 단계에 걸친 실행의 임차 행 규칙은 그대로 옮긴다.
  - **깨진 파일은 덮어쓰지 않고 `CAREER_STORE_CORRUPT` 로 끝낸다.** 백업하지 않는다. 고치는 방법은 파일을 지우고 다시 쌓는 것이다.
  - **분석과 판정의 기준 버전은 맥락 문서 본문의 SHA-256 이다.** 실행기는 작업 폴더 `context/<문서 키>.md` 를 읽고, 줄바꿈과 줄끝 공백, 앞뒤 빈 줄을 정규화한 본문으로 `"<문서 키>:sha256:<hex>"` 를 낸다. 본문이 같으면 다시 분석하지 않는다.
  - **기존 Backend 데이터는 옮기지 않는다.** 처음부터 다시 쌓는다.
  - **단계마다 대체하는 범위가 다르다.**

    | 단계 | 바뀌는 것 | 대체되는 결정 |
    | --- | --- | --- |
    | 1 (이 ADR 을 쓴 PR) | 공고 추천과 공부 추천의 저장 자리, 그 둘의 기준 버전 계산, 두 실행기의 실행 폴더 | ADR-118, ADR-121 의 공고·공부 범위, ADR-131 과 ADR-134 의 기준 버전 계산 |
    | 2 | 면접 연습 저장, 맥락 문서의 원본(기억), 프로필 원고(작업 폴더 파일), 공고 제외 판정 명령 | ADR-131 의 문서 자리, ADR-142 의 MCP 도구 |
    | 3 | 노트북 전용 스킬과 작업본 동기화 삭제 | ADR-138 의 작업본 위치와 동기화 |
    | 5 | Backend 코드 삭제 | ADR-118, ADR-121 전체 |
- **맥락**:
  - 커리어 일을 가족 비서의 대화와 예약 작업으로 옮기면서 운영할 서비스와 데이터베이스를 하나씩 줄이는 것이 목적이다.
  - 비서의 실행 공간은 에이전트 주인의 작업 폴더를 마운트하고, 실행기는 이미 그 안에서 `bun` 으로 돈다. MCP 서버는 작업 폴더에 닿지 못한다.
  - Backend 의 저장소 코드는 Prisma 모델이 아니라 직접 쓴 SQL 이라 테이블과 열 이름을 유지한 채 문법만 옮길 수 있다.
  - 쓰는 사람은 한 명이고 매일 두 번 도는 작업이라 행 단위 동시성이 필요 없다.
- **대안 기각**:
  - **JSON 파일 여러 개**: 임차, 하루 한 번 저장, 버전 대조 같은 조건부 쓰기를 원자적으로 할 수 없다.
  - **비서 Control Plane 에 새 테이블**: 새 테이블을 늘리지 않기로 했고(사용자 결정 2026-11-01), 분야 규칙이 비서 저장소로 넘어간다.
  - **기억 문서 revision 을 기준 버전으로 쓰기**: 본문과 무관한 변경(요약, 넣는 방식)에도 올라 하루 분석 상한을 헛되이 쓴다.
  - **작업 폴더 데이터 백업**: 표 데이터는 다시 쌓을 수 있고 운영 작업을 늘린다(사용자 결정 2026-11-21).
- **결과**:
  - 저장 모듈의 규칙은 Backend 의 기존 계약 기록(`services/career-backend/test/fixtures/legacy-contract/cases.json`)을 다시 돌려 대조한다.
  - 시각은 UTC ISO 문자열로, 날짜는 `YYYY-MM-DD` 로 저장한다. 하루 경계만 서울 날짜로 계산한다.
  - 작업 폴더 배치는 [`docs/data-schema.md`](../data-schema.md) 가 갖는다.
