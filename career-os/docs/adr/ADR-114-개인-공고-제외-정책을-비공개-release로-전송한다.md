# ADR-114 개인 공고 제외 정책을 비공개 release로 전송한다

- Status: Accepted
- Date: 2026-09-10

## 결정

명시적인 개인 공고 제외는 모델 선별 전에 공통 수집기에서 적용한다.
공개 `config/`에는 정책 파일 경로만 두고, 비공개 본문은 `state/private-config/`에서 기존 S3 release로 전송한다.
이 하위 경로는 사람이 관리하는 설정의 전송 예외로 한정한다.
지원 이력의 원본은 private brain에 유지한다.
설정을 읽을 수 없으면 수집을 중단하며, 회사나 직무 이름으로 제외 범위를 확대하지 않는다.

## 이유와 대안

공개 Git에 개인 규칙을 넣으면 지원 판단이 노출될 수 있다.
Git에서 제외한 `config/` 파일만 사용하면 기존 release가 전송하지 않아 자동 실행 환경에서 규칙이 누락된다.
설정 하나를 위해 release 관리 root를 늘리면 archive 검증과 복구 범위까지 바뀐다.
기존 전송 범위를 유지하면서 비공개 설정 예외를 명시하는 방식을 선택한다.

## 적용

필드와 실패 처리는 [데이터 구조](../data-schema.md#개인-공고-제외-설정)가 정의한다.
기존 환경에는 비공개 규칙을 발행하고 수집 코드와 추천 스킬을 함께 배포해야 한다.
