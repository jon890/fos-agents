## ADR-013 외부 읽을거리는 전체 수집 후 모델이 선별한다

- Status: 결정됨
- Date: 2026-05-02
- Updated: 2026-09-03

### 맥락

RSS의 고정 키워드와 소스 우선순위로 글 하나를 먼저 고르면 수집 단계에서 후보가 사라진다.
추천 모델이 좋아져도 이미 잘린 후보는 다시 평가할 수 없다.

### 결정

- 활성 소스는 등록 순서나 우선순위와 무관하게 모두 수집한다.
- RSS·Atom 소스는 최신 항목을 정해진 개수만큼 결정적으로 가져온다.
- 페이지 소스는 공개 HTTPS 페이지와 같은 호스트의 링크를 후보로 만든다.
- 페이지 탐색이 실패하면 원래 출처 페이지를 후보로 유지한다.
- 행사 일정처럼 명백한 저신호 항목만 수집 단계에서 제외한다.
- 이전에 추천한 같은 글과 영상은 누적 이력의 `contentKey`로 판정한다.
- 최종 주제 적합도와 추천 이유는 현재 모델이 이전 추천을 제외한 전체 후보 풀을 보고 판단한다.
- 공식 자료나 최신 소식이어도 현재 업무, 목표 역할, 엔지니어링 판단 또는 제품·사업 관점에 구체적으로 연결되지 않으면 추천하지 않는다.
- 선택한 자료는 외부 원문에서 도출한 공부 주제로 묶는다.
- 모델 출력은 후보 ID, 카테고리, 실행 내 중복, 이전 추천, 문자열 길이와 공부 주제 구성을 런타임에서 검증한다.
- RSS 캐시는 6시간 동안 재사용하며 개별 소스 실패는 전체 실행을 중단하지 않는다.

### 결과

- 수집은 재현 가능하고 추천은 모델 성능 향상의 이점을 받는다.
- 추천 이력은 모델에게 참고 정보만 주는 것이 아니라 코드 검증으로 재선택을 막는다.
- 새로운 후보가 없으면 이전 자료를 다시 채우지 않고 빈 결과를 허용한다.
- `filterKeywords`와 숫자형 소스 우선순위는 설정과 추천 계산에서 제거한다.
- 모델 선택이 없을 때만 최신성과 출처 다양성 기반 예비 선택을 사용한다.
- 피드와 페이지의 차이는 `source/adapters/`가 흡수한다.
