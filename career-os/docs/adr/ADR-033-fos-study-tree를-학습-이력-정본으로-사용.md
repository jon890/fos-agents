## ADR-033 — fos-study tree를 학습 이력 정본으로 사용

- Status: Accepted
- Date: 2026-05-18
- Updated: 2026-08-12

### 맥락

별도 토픽 목록과 후보 저장소가 실제 `sources/fos-study/` 문서와 어긋났다.
추천기가 이를 학습 진도로 사용하면 이미 다룬 주제를 신규 주제로 판단할 수 있다.

### 결정

실제 `sources/fos-study/**/*.md`와 최근 Git 이력을 사용자의 학습 이력 정본으로 사용한다.

- 별도 학습 토픽 목록과 생성 후보 목록을 유지하지 않는다.
- 추천 실행 중 `git pull`이나 문서 수정은 하지 않는다.
- 모델은 실제 문서와 최근 발행 이력을 읽고 관심사와 학습 방향을 판단한다.
- 외부 소스에서 수집한 글만 오늘의 읽을거리 후보가 될 수 있다.

### 거절한 대안

- 별도 토픽 인덱스 유지
  - 실제 문서와의 동기화 비용이 다시 생긴다.
- 고정 학습 선호도 설정
  - 실제 학습 변화가 자동으로 반영되지 않는다.
- 추천 실행 전 자동 동기화
  - 사용자의 로컬 작업 상태를 바꿀 수 있다.

### 결과

- 학습 방향은 실제 발행 이력에서 파생된다.
- career-os는 `fos-study`를 읽기 전용 입력으로 사용한다.
- 새 학습 문서를 자동 생성하거나 발행하지 않는다.
