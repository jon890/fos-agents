# HTML 이력서 채점 기준

## 채점 원칙

- 총점은 100점이다.
- 각 점수는 HTML의 구체 위치와 근거 문장으로 설명한다.
- 치명적 결함은 총점보다 우선한다.
- 인재풀 지원서는 특정 기술 일치율보다 매칭 가능한 직업 정체성과 재사용 가능한 강점을 더 중요하게 본다.
- 빅테크 기준에서 `무난함`은 통과 이유가 아니다. 다음 단계에서 검증할 가치가 분명해야 한다.

## 축별 감점 기준

### 첫 화면과 포지셔닝 — 10점

- 목표 역할이 없거나 두 개 이상 충돌한다: -4~-7
- 경력 연차와 핵심 분야를 첫 화면에서 찾기 어렵다: -2~-4
- 차별점이 추상적인 성격 표현에 머문다: -2~-3
- 연락 방법이나 공개 작업 링크가 없다: -2~-3

### 경력 서사와 지원 동기 — 10점

- 최근 역할과 이전 경력이 끊겨 보인다: -2~-5
- 현재 조직을 벗어나려는 방어적 표현이 중심이다: -2~-5
- 회사 이름만 바꿔도 그대로인 지원 동기다: -2~-4
- 목표 역할이 실제 경력의 다음 단계로 보이지 않는다: -2~-5

### 제품·사업 연결 — 12점

- 기술 구현만 있고 사용자 문제가 없다: -3~-7
- 제품 지표 또는 의사결정 관점이 전혀 없다: -2~-5
- 실제 경험보다 열망 문장이 더 길다: -2~-4
- 사업 성과를 암시하지만 확인 가능한 연결 근거가 없다: -2~-5

### 선별과 훑어보기 — 8점

- 첫 페이지가 긴 문단과 기술 목록으로 과밀하다: -2~-5
- 다음 단계로 넘길 대표 사례가 세 개를 넘어서 분산된다: -1~-3
- 첫 대표 사례가 직무 적합성보다 구현 세부사항의 양으로 선택됐다: -2~-4
- 중요도가 다른 설명을 같은 크기의 카드에 넣어 시선 흐름이 사라진다: -2~-4
- 동일 의미의 문장이 반복된다: -1~-2

### 문제 난도와 소유 범위 — 12점

- 해결한 문제가 왜 어려웠는지 드러나지 않는다: 주요 사례당 -2~-4
- 본인 소유 범위와 팀 소유 범위가 구분되지 않는다: -3~-6
- 구현 동사만 있고 판단이나 책임이 없다: -2~-5

### 기술 결정과 절충안 — 12점

- 기술 키워드만 있고 왜 선택했는지 없다: 주요 사례당 -2~-4
- 대안 또는 제약이 전혀 드러나지 않는다: -2~-5
- 부분 실패, 복구, 동시성 같은 운영 경계가 빠진다: -2~-5

### 측정·안정성·검증 — 12점

- 수치가 있지만 출처 또는 맥락이 없다: 건당 -3~-6
- 행동만 있고 결과 또는 검증 방법이 없다: 주요 사례당 -2~-4
- 성능·품질 개선에 기준선이나 회귀 검증이 없다: -2~-5

### 깊이와 신뢰도 — 9점

- 기술 키워드만 20개 이상 나열하고 선택 근거가 없다: -2~-5
- 공고 기술을 맞추기 위한 근거 없는 추가가 있다: -5~-10
- 단기 경험을 장기 운영·전문성으로 확대한다: -4~-8
- 예상 심층 질문에 답할 근거가 없다: 주요 주장당 -2~-4

### 근거·과장·공개 안전 — 5점

- 근거 없는 수치 또는 역할이 있다: -5점과 치명적 결함
- 팀 결과를 개인 단독 성과로 바꾼다: -5점과 치명적 결함
- 로컬 경로, 내부 검토 토큰, 비공개 정보가 노출된다: -5점과 치명적 결함

### 정보 구조와 문장 — 5점

- 같은 의미가 여러 섹션에 반복된다: -1~-3
- 짧은 설명을 카드 안에 가둬 문맥이 끊기거나 글자 크기가 작아진다: -1~-3
- 한 문장이 지나치게 길거나 주어와 결과가 모호하다: 건당 -1
- 9pt 미만 본문으로 내용을 압축한다: -3~-5

### HTML·A4 출력 품질 — 5점

- 외부 스크립트나 글꼴이 없으면 깨진다: -3~-5
- A4 인쇄 CSS 또는 페이지 구분이 없다: -4~-5
- 페이지 넘침, 겹침, 잘린 내용이 있다: -5점과 치명적 결함
- 링크 텍스트가 불명확하거나 접근성이 약하다: -1~-2
- 색 대비가 낮거나 색만으로 정보를 구분한다: -1~-2

## 치명적 결함과 점수 상한

| 결함 | 판정 | 총점 상한 |
| --- | --- | ---: |
| 근거 없는 수치·경력·역할, 심각한 과장 | blocked | 59 |
| 비공개 내부 경로, 개인정보 또는 회사 기밀 노출 | blocked | 59 |
| 목표 역할, 경력 기간, 연락 수단 중 둘 이상 누락 | revise | 69 |
| 외부 자산 의존으로 오프라인 렌더가 깨짐 | revise | 79 |
| 인쇄 시 페이지 넘침·겹침·잘림 | revise | 79 |

## 판정

- `pass`: 90점 이상, 인사 32/40 이상, 기술 36/45 이상, 제출 품질 12/15 이상이며 치명적 결함이 없다.
- `revise`: 60~89점이거나 평가자별 하한에 미달하거나 수정 가능한 치명적 결함이 있다.
- `blocked`: 59점 이하이거나 후보자 확인 없이는 고칠 수 없는 사실 문제가 있다.
