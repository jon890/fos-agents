# career-os 출력 정책

career-os skill이 리포트, 지원 패키지, 공개 공부 자료, 면접 자산을 만들 때 따른다.
각 skill의 `SKILL.md`에는 이 문서와 다른 점만 남긴다.

## 공통 원칙

- 내부 분석과 외부에 옮길 수 있는 문구를 분리한다.
  제출용 문구, 공개 공부 자료, 외부 요약에는 내부 경로와 실행 정보를 넣지 않는다.
- 근거가 부족한 항목은 raw marker로 남기지 않는다.
  `needs_evidence`는 보강 필요, 선택지, 권장 행동으로 나누어 다음 행동을 명시한다.
- 실제 외부 제출, 로그인, 전송, 공개 발행, 채용 사이트 입력, candidate-profile 수정은 사용자 승인 전에 실행하지 않는다.

## 공개 산출물

- `fos-study` 공개 글에 후보자 private 맥락, 특정 회사 지원 전략, reviewer 판단을 넣지 않는다.
- 사용자 검토 전 공개 글은 제목에 `[\ucd08\uc548]`을 유지한다.
  사용자가 해당 산출물을 검토하고 최종화 또는 발행을 승인한 뒤에만 제거한다.
- 특정 공고, 면접, 지원서와 연결한 해석은 `applications/` 또는 `private/` 아래 비공개 산출물에 둔다.
- 갭 학습 문서는 제목에 `[학습중]`을 유지한다.
  frontmatter `tags`에 `학습중`, 도메인, 기술 주제를 기록한다.
- 회사 태그를 사용자가 명시적으로 요청하면 회사명을 frontmatter `tags`에만 기록할 수 있다.
  제목과 본문은 특정 지원 전략이 아닌 일반 학습 내용으로 유지한다.
- 기존 완성 문서를 보강해도 제목 상태와 회사 태그는 기본적으로 보존한다.
  사용자가 상태 전환을 명시한 경우에만 `[학습중]`으로 바꾼다.
- 최초 요청의 포괄적 발행 지시는 초안 생성 승인으로만 본다.
  미리보기와 검증 결과를 제시한 뒤 받은 해당 산출물의 승인만 실제 발행 승인으로 인정한다.

## 비공개 산출물

- 비공개 리포트에는 판단 근거 경로와 위험 신호를 유지한다.
- 제출용으로 옮길 수 있는 문장은 내부 근거와 분리해서 작성한다.
- 외부 요약에 private 지원 전략이나 이력서 문구를 그대로 노출하지 않는다.
