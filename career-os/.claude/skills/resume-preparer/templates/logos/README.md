# 이력서 로고

## 붙는 방식

`index.json` 의 `map` 이 이력서의 `h3` 제목과 파일을 잇는다.
제목이 key 로 시작하면 그 로고가 붙고, 매핑에 없는 이름은 로고 없이 렌더한다.

새 회사를 더하려면 이미지를 이 디렉터리에 두고 `map` 에 한 줄을 더한다.
렌더러가 base64 로 인라인하므로 HTML 과 PDF 가 외부 이미지에 의존하지 않는다.

## 출처

사용자가 2026-09-06 제공한 원티드 이력서 PDF에서 추출했다.

- NHN: 원본 1쪽의 회사 로고
- 더퓨쳐컴퍼니: 원본 2쪽의 회사 로고
- 전남대학교: 원본 3쪽의 학교 로고와 투명도 마스크

엠씨에스텍은 원본에 기본 아이콘만 있고 공식 홈페이지에 연결할 수 없어 로고를 두지 않았다.
