# 원격 검증

| 선행 조건 | 실행 위치 | 명령 | 기대값 |
|---|---|---|---|
| PR 생성 뒤 | GitHub | `gh pr checks --watch` | 필수 검사 성공 |
| 머지 뒤, 코디네이터 수행 | 관리 화면/API | 분야 스킬 본문 읽기, 최신 SKILL.md와 references 전체 재업로드 | v3 본문과 예시 확인 |
| 재업로드 뒤, 코디네이터 수행 | 운영 수동 살펴보기 | 명시된 목표와 확인 가능한 원문으로 1회 실행 후 해당 실행의 문제 후보 읽기 | ACCEPTED 또는 까닭이 있는 DROPPED 저장 |
