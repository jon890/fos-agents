## ADR-021 — 결정론적 처리와 agent 해석을 분리한다

- Status: Accepted
- Date: 2026-08-11

### 맥락

외부 데이터 수집과 정규화는 같은 입력에서 같은 결과와 명시적인 실패를 제공해야 한다.
반면 여러 근거를 비교하고 사람이 읽는 설명을 만드는 일은 agent 해석이 더 적합하다.
두 책임을 한 계층에 넣으면 재현 가능한 오류와 판단 품질 문제를 구분하기 어렵다.

### 결정

- 수집, 파싱, 정규화, 형식 검증은 결정론적 코드가 담당한다.
- agent workflow는 검증된 산출물을 읽고 비교, 판단, 설명을 담당한다.
- agent 판단이 다시 상태 변경에 쓰이면 결정론적 검증을 통과한 뒤 반영한다.

### 거절한 대안

- 수집까지 agent 추론에 맡기면 재실행 결과와 실패 원인을 고정하기 어렵다.
- 판단까지 정적 template에 넣으면 맥락 비교와 불확실성 설명이 제한된다.

### 결과

데이터 처리 실패와 해석 실패를 분리하고 같은 수집 자산을 여러 workflow에서 재사용할 수 있다.
