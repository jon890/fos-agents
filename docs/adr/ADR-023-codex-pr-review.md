# ADR-023 PR 리뷰는 Codex 클라우드 리뷰로 받는다

- Status: Accepted
- Date: 2026-11-23

## 맥락

PR이 열리면 GitHub Actions의 Claude 리뷰(`claude-review`)가 자동으로 돌았다.
리뷰에 쓰는 Claude 토큰이 만료되면서 최근 모든 PR에서 이 검사가 시작 직후 실패했다.
그동안 머지 전 리뷰는 코디네이터가 하위 에이전트를 띄워 대신했다.
사용자는 PR 리뷰를 Codex 클라우드 코드 리뷰로 바꾸기로 정했다(사용자 결정 2026-11-23).

## 결정

PR 리뷰는 Codex 클라우드 코드 리뷰가 맡는다.

- PR을 Ready로 올리면 Codex 자동 리뷰가 돈다(Draft에서 Ready로 바꿀 때도 돈다).
  10분이 지나도 Codex 리뷰가 없을 때만 `@codex review` 댓글을 한 번 단다. 둘 다 하면 리뷰가 두 번 돈다.
  리뷰를 반영한 뒤에는 다시 부르지 않는다.
- Codex는 루트 `AGENTS.md`의 「Code Review Rules」를 읽는다. 그 절이 등급(P1~P5, P1과 P2가 차단), 건수 표와 판정 줄 형식을 정한다.
  등급 기준과 리뷰 관점은 `.github/workflows/code-review-prompt.txt`를 가리키며 두 곳에 복제하지 않는다.
- 머지 큐는 리뷰 본문의 판정 줄(`판정: 머지 가능, …` 또는 `판정: 반영 필요, …`)을 읽어 자동 머지 여부를 정한다.
  그래서 판정 줄의 문구와 순서는 바꾸지 않는다.
  지적이 없으면 Codex는 판정 줄 없이 `Codex Review: Didn't find any major issues.` 댓글만 다는데, 머지 큐는 이 문구도 통과로 읽는다.
- Claude 리뷰 workflow는 지우지 않고 자동 실행만 끈다. Actions에서 PR 번호를 넣어 수동 실행하거나, 권한 있는 사용자가 PR에 `/review` 댓글을 달면 돈다.
  돌 때는 같은 건수 표와 판정 줄을 쓴다.

## 기각한 대안

- Claude 토큰을 새로 발급해 자동 리뷰를 유지한다. 만료가 되풀이되면 같은 장애가 다시 나고, 사용자가 리뷰 도구를 바꾸기로 정했다.
- Claude 리뷰 workflow를 지운다. Codex가 응답하지 않을 때 같은 기준으로 다시 리뷰할 수단이 없어진다.
- 리뷰를 반영할 때마다 `@codex review`를 다시 부른다. 비차단 제안이 반영마다 새로 달려 머지가 늦어진다.

## 결과

PR마다 실패하던 `claude-review` 검사가 더는 자동으로 돌지 않는다.
리뷰 형식이 판정 줄로 고정돼 머지 큐가 사람 확인 없이 결과를 읽는다.
이 저장소가 Codex 저장소 연결에서 빠지면 리뷰가 오지 않으므로, 그때는 Claude 리뷰를 수동으로 돌린다.
