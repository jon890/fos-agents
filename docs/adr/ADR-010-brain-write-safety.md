## ADR-010 — 외부 지식 기반은 호출만 하고 쓰기는 사용자 검토 뒤 수행한다

- Status: Accepted
- Date: 2026-05-28

### 맥락

개인 지식 기반은 별도 저장소와 skill이 스키마, 출처, 공개 범위를 관리한다.
이 저장소가 같은 로직을 재구현하면 규칙이 갈라지고 비공개 자료가 공개 영역으로 이동할 위험이 있다.

### 결정

- 지식 기반의 스키마와 편집 로직은 외부 skill을 단일 출처로 둔다.
- 이 저장소는 지식 기반 파일을 직접 수정하지 않고 설치된 skill을 호출한다.
- 읽기는 작업 문맥 보강에 사용할 수 있다.
- 쓰기는 사용자가 명시적으로 요청하고 공개 범위를 검토한 뒤 수행한다.
- 일반화된 공개 지식만 public으로 보내며 개인 자료는 private을 기본값으로 둔다.
- 설치 경로와 계정명 같은 환경 고유 값은 저장소 문서에 기록하지 않는다.

### 거절한 대안

- 지식 기반 파일을 직접 편집하면 백링크와 출처 규칙을 우회한다.
- 자동 실행에서 무인 쓰기를 허용하면 잘못된 지식과 민감 정보가 누적될 수 있다.

### 결과

지식 기반은 독립적으로 진화하고 이 저장소는 안전한 호출자 역할만 유지한다.
