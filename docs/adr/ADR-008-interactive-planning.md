## ADR-008 — 열린 결정은 대화로 닫고 구현은 확정된 범위에서 수행한다

- Status: Accepted
- Date: 2026-05-26

### 맥락

공개 범위, 외부 제출, 데이터 경계처럼 결과를 바꾸는 결정은 비대화형 실행만으로 확정하기 어렵다.
반면 범위와 검증 기준이 닫힌 구현은 자동 실행에 적합하다.

### 결정

- 결과가 달라지는 열린 결정은 사용자와 대화해 확정한다.
- 구현은 목표, 범위, 검증, 중단 조건이 정해진 뒤 시작한다.
- 구현 도구는 특정 agent 제품으로 고정하지 않는다.
- 완료를 주장하기 전에 현재 실행 환경에서 검증한다.

### 거절한 대안

- 열린 결정을 자동으로 추정하면 사용자의 공개·외부 작업 경계를 넘을 수 있다.
- 모든 구현을 대화형으로만 수행하면 반복 작업의 자동화 이점을 잃는다.

### 결과

사용자 판단이 필요한 단계와 자율 실행 가능한 단계를 분리할 수 있다.
