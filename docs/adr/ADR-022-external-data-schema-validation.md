## ADR-022 — 외부 데이터는 경계에서 스키마로 검증한다

- Status: Accepted
- Date: 2026-08-11

### 맥락

외부 API와 agent 산출물은 예고 없이 필드가 누락되거나 형식이 달라질 수 있다.
검증하지 않은 값을 내부 상태와 리포트에 전달하면 오류가 늦게 발견되고 원인을 추적하기 어렵다.

### 결정

- 신뢰 경계를 넘어오는 구조화 데이터는 내부 상태로 사용하기 전에 runtime schema로 검증한다.
- 필수 계약은 엄격히 확인하고 호환 가능한 추가 필드는 허용할 수 있다.
- TypeScript에서는 저장소의 기존 `zod` 의존성을 우선 사용한다.
- 검증 실패 값은 상태 전이나 확정 사실로 사용하지 않는다.

### 거절한 대안

- 정적 type cast만 사용하면 runtime 응답 변경을 발견할 수 없다.
- 모든 추가 필드를 거부하면 호환 가능한 외부 확장에도 전체 수집이 실패한다.

### 결과

외부 변경을 경계에서 발견하고 잘못된 값이 후속 판단으로 전파되는 범위를 줄인다.
