## ADR-017 — 반복 실패 패턴은 항목별 파일로 분리한다

- Status: Accepted
- Date: 2026-06-17

### 맥락

반복 실패 사례를 한 문서에 계속 추가하면 모든 작업이 무관한 내용을 함께 읽게 된다.

### 결정

- 반복 실패 패턴은 `.claude/skills/_shared/common-pitfalls/` 아래 항목별 파일로 둔다.
- `INDEX.md`는 관련 패턴을 찾는 목록만 담당한다.
- 작업자는 현재 범위와 관련된 항목만 읽는다.
- 같은 원인이 반복되는 경우에만 새 패턴을 추가한다.

### 거절한 대안

- 단일 거대 문서는 검색은 쉽지만 문맥 비용과 충돌 가능성이 계속 증가한다.
- 모든 skill에 같은 내용을 복사하면 수정 시점이 갈라진다.

### 결과

실패 패턴을 재사용하면서도 작업별 문맥을 작게 유지할 수 있다.
