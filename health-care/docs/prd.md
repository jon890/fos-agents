# PRD — health-care

## 목적

개인 건강 기록, 재활 경과, 진료 준비를 장기적으로 관리한다.
의료진 판단을 대체하지 않고 기록·요약·체크인을 돕는다.

## 사용자

본인 1인.
건강 기록을 잊지 않고 누적하고, 진료 전 핵심을 빠르게 정리하는 것이 목적이다.

## 현재 MVP

| 기능 | 목적 | 판단 범위 |
|---|---|---|
| `daily-health-coaching` | 하루 건강·재활 체크인 | 저장된 상태와 공개 플랜 기반 보수적 안내 |
| `knee-progress-intake` | 증상과 운동 반응 누적 | 사용자가 말한 사실 구조화 |
| `weekly-knee-clinic-summary` | 병원 제출용 요약 초안 | 경과 요약과 질문 정리 |
| `personalized-healthy-meal-research` | 건강 목표 기반 식단 리서치 | 생활 조절 아이디어 제안 |

## 성공 기준

- 민감 의료정보는 `private/` 밖으로 나가지 않는다.
- 공개 가능한 일반 기준은 `config/`에서 관리한다.
- 체크인은 짧고 보수적이며 중단 기준을 포함한다.
- 병원 요약은 확정 사실, 사용자 보고, 불확실성, 확인 필요를 구분한다.
- 위험 신호가 있으면 의료기관 재평가를 우선한다.

## 비범위

- 진단
- 처방
- 약물 변경
- 의료진 판단 대체
- 응급 상황 판정 대체
- 개인 건강 정보 공개 발행
