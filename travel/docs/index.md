# Travel Index

이 저장소는 공개 저장소다.
실제 trip 목록은 개인 날짜와 목적지를 포함하므로 여기에 두지 않는다.

| 목록 | 위치 | 공개 여부 |
|---|---|---|
| 개인 trip 목록 | `private/trips/index.md` | 비공개 (Git 무시) |
| 공개 승인된 trip | 아래 표 | 공개 |

## 공개 trip

현재 공개 승인된 trip은 없다.

비식별화하고 사용자의 명시적 승인을 받은 trip만 이 표에 추가한다.
공개 경계는 [`../AGENTS.md`](../AGENTS.md)의 데이터 경계를 따른다.
