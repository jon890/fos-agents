# AGENTS.md: accountbook 워크스페이스

`accountbook`는 개인 가계부 입력 자동화를 관리하는 독립 워크스페이스다.
토스 소비 화면에서 거래 후보를 추출하되, 검증되지 않은 결과를 가계부에 등록하지 않는다.

## 금융 데이터 경계

- 원본 이미지, 추출한 거래 후보와 API 응답 원문을 파일로 저장하지 않는다.
- 목록의 파일 출력만 사용자별 출력 디렉터리에 검증한 거래 필드를 JSONL로 저장한다. 보관 계약은 `docs/data-schema.md`를 따른다.
- 연동 토큰은 사용자별 환경 변수로 전달하며 MCP 서버가 파일에 저장하지 않는다.
- 공개 문서와 fixture에는 실제 이름, 계좌, 카드, 가맹점, 금액을 넣지 않는다.
- 로그에는 인증 값, 화면에서 읽은 원문과 API 응답 본문을 남기지 않는다.

## 등록 안전 규칙

- 이미지 인식 결과는 거래 후보일 뿐이며 결정적 검증을 통과하기 전에는 등록하지 않는다.
- 일별 수입·지출 합계가 화면 요약과 일치하지 않으면 등록하지 않는다.
- 화면에서 잘린 날짜와 거래 시각을 추정해 채우지 않는다.
- 같은 날짜, 금액, 설명의 기존 기록은 그 건수만큼 이미 등록된 것으로 보고 다시 등록하지 않는다. 건너뛴 건수는 미리보기에 보여 준다.
- 사용자가 미리보기를 확인하고 등록을 명시한 뒤에만 등록 도구를 호출한다.
- 등록 도중 실패하면 미리보기를 다시 만들어 남은 거래만 등록한다.

## 실행 경계

- 스킬은 화면 읽기, 미리보기 제시, 사용자 확인과 오류 안내를 맡는다.
- `plugin/src/`의 MCP 도구는 스키마 검증, 합계 계산, 기존 기록 대조와 API 등록을 맡는다.
- 에이전트 실행 환경과 사진을 전달하는 방법은 저장소 밖에서 선택한다.
- 이미지 입력을 지원하지 않는 실행 환경에서는 `OCR_UNAVAILABLE`로 중단한다.

## 스킬 문체

- 스킬의 제목, 설명과 실행 절차는 자연스러운 한국어로 작성한다.
- 명령어, 경로, 파일명, 코드 식별자와 상태값처럼 정확한 원문이 필요한 값만 영문으로 유지한다.

## 현재 스킬

| 스킬 | 목적 |
|---|---|
| `accountbook-api` | 토스 소비 화면 검증·미리보기와 가족 가계부 조회. 등록·수정·삭제는 사용자가 승인 카드에서 승인한 것만 실행하며 삭제는 한 건씩 매번 승인 |
