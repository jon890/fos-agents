## ADR-001: vision 추출과 결정적 검증을 분리한다

- Status: Accepted
- Date: 2026-08-20

### 맥락

금융 스크린샷은 화면 문맥과 행 경계를 함께 읽어야 하지만 OCR 결과에는 금액과 날짜 오류가 생길 수 있다.
홈서버 자동화는 특정 운영체제의 OCR API나 agent runtime에 묶이지 않아야 하며, 잘못된 추출이 곧바로 가계부 상태를 바꾸면 안 된다.

### 결정

- vision 지원 agent는 화면에서 거래 후보와 근거를 추출한다.
- 스키마, 날짜, 금액, 일별 합계와 등록 상태는 결정적 TypeScript script가 검증한다.
- 사용자 승인과 결정적 검증을 모두 통과한 후보만 기존 accountbook API에 등록한다.
- 선형 workflow와 private 상태 파일로 복구 가능한 동안은 LangGraph를 도입하지 않는다.

### 대체된 부분

[ADR-002](ADR-002-weekly-safe-policy-auto-submission.md)는 사용자 승인 요구 중 주간 실행을 대체한다.
대화형 실행은 사용자 승인을 유지하고, 주간 실행은 결정적 안전 정책을 승인 주체로 사용할 수 있다.

### 거절한 대안

- macOS Vision 전용 구현은 Linux 기반 홈서버와 runtime 독립 경계를 만족하지 못한다.
- 외부 OCR API 고정은 금융 이미지의 외부 전송과 공급자 운영 비용을 기본값으로 만든다.
- agent가 추출과 등록을 모두 판단하면 오류를 재현하고 차단한 근거를 확인하기 어렵다.
- 초기부터 LangGraph를 사용하면 현재 선형 단계보다 상태 저장과 운영 책임이 커진다.

### 결과

OCR 정확도 개선과 등록 안전 검증을 독립적으로 바꿀 수 있다.
vision을 지원하지 않는 runtime은 별도 OCR adapter가 생기기 전까지 실행할 수 없다.
