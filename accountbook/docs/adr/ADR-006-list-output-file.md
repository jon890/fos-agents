# ADR-006: 목록 파일을 코드로 계산한다

- Status: Accepted
- 날짜: 2026-10-08

## 배경

기간 통계마다 집계 도구를 추가하면 도구 수와 집계 방식이 함께 늘어난다.
사용자는 합계 도구를 두지 않고 전체 목록 파일을 `execute_code` 스크립트로 계산하기로 결정했다.

## 결정

- `list_expenses`와 `list_incomes`에 선택 입력 `output: "inline" | "file"`을 둔다.
- 파일 모드는 기간 전체를 검증하고 실행 환경이 지정한 사용자별 디렉터리에 필요한 거래 필드만 저장한다.
- 파일 계약과 보관 기간은 [데이터 계약](../data-schema.md#mcp-계약)을 따른다.
- 커넥터는 합계나 통계를 계산하는 도구를 제공하지 않는다. 모델은 코드 실행 결과로 답한다.
- 코드 실행 도구가 없으면 통계 계산을 할 수 없다고 안내한다.

## 영향

ADR-005의 화면 가져오기와 등록 상태는 계속 메모리에만 둔다.
목록 파일 출력에 한해 금융 데이터의 파일 저장을 허용하며 출력 디렉터리의 사용자 격리는 실행 환경이 맡는다.
24시간 삭제는 새 파일을 쓸 때 수행하므로 조회가 없으면 오래된 파일이 남을 수 있다.
inline 목록과 등록·수정·삭제 도구의 계약은 유지한다.
