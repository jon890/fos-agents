# ADR-004: 가계부 connector를 MCP plugin으로 배포한다

- **status**: `accepted`
- **결정**: 가계부 공개 API와 단일 대화 스킬을 MCP plugin으로 연결한다. MCP 서버는 사용자별 환경 변수만 읽고 파일 상태를 만들지 않는다.
- **맥락**: 가계부 전용 에이전트가 셸과 파일 도구 없이 기록을 관리해야 한다. 여러 사용자가 같은 저장소 마운트를 공유하므로 토큰과 실행 상태의 소유자를 분리해야 한다.
- **대안 기각**: 에이전트가 스크립트를 직접 실행하는 방식은 셸 권한을 요구한다. 작업별 스킬 분리는 가족과 카테고리 선택 흐름을 중복시킨다. 런타임 의존성 설치는 profile 기동에 패키지 설치를 요구한다.
- **결과**:
  - 얻는 것: 조회·등록·수정·삭제를 MCP 도구만으로 수행하며, 설치 없이 실행 파일을 배포한다.
  - 감당할 것: 소스를 바꿀 때 번들을 다시 빌드하고 함께 커밋해야 한다. 화면 가져오기도 같은 plugin의 도구로 수행한다([ADR-005](ADR-005-screenshot-import-as-mcp-tools.md)).
