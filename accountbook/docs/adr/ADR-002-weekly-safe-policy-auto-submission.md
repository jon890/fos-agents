## ADR-002: 검증된 주간 후보는 안전 정책으로 자동 등록한다

- Status: Accepted
- Date: 2026-08-25

### 맥락

주마다 토스 화면을 직접 확인하고 같은 거래를 가계부에 다시 입력하는 과정은 반복 비용이 크다.
기존 흐름은 모든 등록에 사용자 확인을 요구해 예약 실행이 후보 생성에서 멈춘다.
반면 OCR 결과를 조건 없이 승인하면 잘못된 금액과 날짜가 금융 기록에 들어갈 수 있다.

### 결정

- [ADR-001](ADR-001-vision-extraction-deterministic-validation.md)의 사용자 승인 요구 중 주간 실행 부분을 대체한다.
- 대화형 실행의 사용자 승인은 유지한다.
- 주간 실행은 `weekly-safe-v1`의 합계, 필드 신뢰도, 원본 생성 시각과 중복 검사를 모두 통과한 후보만 자동 등록한다.
- 모든 이미지 인식 검증 이후 단계는 결정적 주간 실행기가 맡고, 주간 등록은 `weekly-safe-v1` 승인 출처를 필수로 검사한다.
- 정책을 벗어난 후보와 전송 결과가 불명확한 후보는 자동 재전송하지 않고 검토 상태로 분리한다.
- 거래 생성 POST의 5xx와 네트워크 오류는 `submitting`으로 남기고 기존 거래 조회로만 복구한다.
- 정책 버전과 승인 주체를 비공개 승인 산출물에 기록한다.

### 거절한 대안

- 모든 주간 후보 자동 승인은 OCR 오류를 차단할 결정적 경계가 없어 거절한다.
- 모든 주간 후보 사용자 승인은 반복 입력 비용을 줄이는 목표를 충족하지 못해 거절한다.
- LangGraph 도입은 현재의 선형 탐색, 검증, 등록과 파일 상태 전이에 비해 운영 책임이 커 거절한다.

### 결과

정확한 합계와 제한된 날짜 추론을 가진 후보는 사람의 개입 없이 등록된다.
자동화율보다 잘못된 금융 기록 방지를 우선하므로 긴 화면, 중복 후보와 불확실한 필드는 검토 대상으로 남는다.
