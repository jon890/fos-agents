## ADR-003: Discord 첨부 이미지는 Hermes 입력 어댑터로 받는다

- Status: Accepted
- Date: 2026-08-25

### 맥락

사용자는 iPhone에서 토스 화면을 캡처한 뒤 별도 단축어나 업로드 화면을 거치지 않고 Hermes와 연결된 Discord로 보내려 한다.
Hermes는 허용된 사용자의 Discord 첨부 이미지를 홈서버 캐시에 저장하고 vision 입력으로 전달할 수 있다.
다만 Discord는 iPhone 사진의 원본 생성 시각을 자동 등록에 사용할 수 있는 형태로 보장하지 않는다.

### 결정

- Discord 수신은 새 입력 어댑터가 맡고 화면 추출, 검증과 accountbook API 등록은 기존 흐름을 재사용한다.
- Hermes 캐시는 장기 입력 저장소로 사용하지 않고, 이미지를 받은 실행 안에서 비공개 입력함으로 옮긴다.
- Discord 사용자 허용 목록과 전용 채널 권한은 Hermes 운영 설정에서 제한한다.
- Discord 수신 시각으로 연도를 보완하되 선택한 거래 날짜가 최근 14일 안에 있을 때만 `weekly-safe-v1` 자동 등록을 허용한다.
- 처리 결과는 건수와 안정된 상태 코드만 Discord에 회신한다.

### 거절한 대안

- iPhone 단축어 전용 업로드 API는 사용자가 원하는 Discord 중심 흐름에 불필요한 조작과 운영 요소를 더하므로 사용하지 않는다.
- Hermes 캐시를 주간 실행 때까지 유지하는 방식은 캐시 정리 정책에 처리 성공이 의존하므로 사용하지 않는다.
- Discord 메시지마다 새로운 추출·등록 구현을 두는 방식은 기존 안전 정책과 중복 방지 경계를 복제하므로 사용하지 않는다.

### 결과

사용자는 전용 Discord 채널에 이미지 한 장을 보내는 것으로 가계부 등록을 시작할 수 있다.
금융 이미지가 Discord를 거치는 개인정보 노출 가능성은 남으며, 메시지 삭제가 Discord 저장소의 완전 삭제를 보장하지 않는다.
