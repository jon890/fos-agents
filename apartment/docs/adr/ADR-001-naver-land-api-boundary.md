## ADR-001 — Naver Land API 수집 경계

- Status: Accepted
- Date: 2026-04-24

### 맥락

화면 자동화는 차단과 UI 변경에 취약하다.
로그인 세션으로 접근 가능한 API는 단지 개요, 공식 시세, 매물 호가를 더 안정적으로 제공한다.

### 결정

- 수집 대상은 단지 개요, 시세, 매물 API로 제한한다.
- 인증 값은 실행 환경에서 주입하고 공개 리포트에 포함하지 않는다.
- 요청 간격과 재시도 제한을 두며 실패 시 다른 출처와 마지막 정상 snapshot을 사용할 수 있다.

### 거절한 대안

- 화면 자동화는 차단과 UI 변경 대응 비용이 크다.
- 인증 없는 비공식 호출은 재현할 수 없다.

### 결과

필요한 데이터만 요청하고 단일 출처의 인증 실패를 전체 리포트 실패로 확대하지 않는다.
