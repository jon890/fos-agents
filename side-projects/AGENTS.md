# fos-side 작업 지침

## Skill 작성과 유지보수

스킬을 새로 만들거나 수정할 때는 사용자가 직접 읽고, 유지보수하고, 의견을 제시할 수 있도록 구성한다.

- `SKILL.md`, `references/` 문서는 기본적으로 한국어로 작성한다.
- 문장은 짧게 쓰고, 한 문장 또는 의미 단위마다 줄을 나눈다.
- 절차, 기준, 예외는 표나 목록으로 분리한다.
- 기술 식별자, 경로, 명령어, `$skill-name`, 코드 심볼은 번역하지 않는다.
- 반복 실행 스크립트는 `scripts/`로 분리하고, 스크립트의 역할과 입력 형식은 한국어 문서에서 설명한다.
- 사용자가 수정하기 어려운 압축된 영어 설명이나 긴 단락을 피한다.

## 외주 공고 평가

외주 공고를 수집하거나 분류할 때는 리모트 가능 여부를 필수 조건으로 본다.

- 상주, 반상주, 파견, 정기 출근, 현장 테스트가 필요한 공고는 제외한다.
- 일부 대면 미팅이 있더라도 실제 개발, 검수, 수정, 배포가 원격으로 끝나지 않으면 제외한다.
- 공고가 매력적이어도 `주 N일 상주`가 명시되어 있으면 지원 후보로 올리지 않는다.
- 와이어프레임 기반 웹 디자인, UI 디자인, 퍼블리싱, HTML/CSS 마크업만 수행하는 공고는 사용자와 맞지 않으므로 수집·지원 후보에서 제외한다.
- 단, 관리자 화면·대시보드·업무자동화·AI/API 연동처럼 실제 기능 구현이 포함된 경우에는 별도 평가한다.
- 크몽·숨고 상품 등록이나 경쟁상품 조사는 기본 외주 공고 리포트 범위에서 제외한다.
