# AGENTS.md — side-projects 워크스페이스

`side-projects`는 개인 사이드 프로젝트와 외주 기회 탐색을 관리하는 워크스페이스다.
이 파일은 평가 기준과 작업 경계만 담는다.

## 범위

- 외주 공고 수집과 분류
- 리모트 가능성 검토
- 지원 후보 리포트 생성
- 지원 전 체크리스트와 제안서 준비
- 사이드 프로젝트 아이디어 정리

## 읽기 순서

| 문서 | 책임 |
|---|---|
| `README.md` | 범위, 구조, 실행 방법 |
| `.claude/skills/freelance-opportunity-reporter/SKILL.md` | 외주 후보 수집 리포트 |
| `.claude/skills/freelance-proposal-preparer/SKILL.md` | 지원 제안서 준비 |

## 외주 공고 평가

- 리모트 가능 여부를 필수 조건으로 본다.
- 상주, 반상주, 파견, 정기 출근, 현장 테스트가 필요한 공고는 제외한다.
- 개발, 검수, 수정, 배포가 원격으로 끝나지 않으면 지원 후보로 올리지 않는다.
- 와이어프레임 기반 웹 디자인, UI 디자인, 퍼블리싱, HTML/CSS 마크업만 수행하는 공고는 제외한다.
- 관리자 화면, 대시보드, 업무자동화, AI/API 연동처럼 실제 기능 구현이 있으면 별도 평가한다.
- 크몽·숨고 상품 등록이나 경쟁상품 조사는 기본 외주 공고 리포트 범위에서 제외한다.

## 작업 경계

- `side-projects/.gitignore`는 사용자 변경 보호 파일로 취급한다.
- 지원, 견적 제출, 외부 메시지 전송은 사용자 확인 후에만 한다.
- 공고 URL, 수집 시각, 판단 근거를 리포트에 남긴다.
- 로그인이나 결제가 필요한 행동은 자동으로 진행하지 않는다.
