# side-projects

개인 사이드 프로젝트와 외주 기회 운영을 관리하는 워크스페이스다.
현재 핵심은 리모트 외주 후보를 수집하고 지원 가능성을 판단하는 일이다.

## 구조

| 경로 | 용도 |
|---|---|
| `AGENTS.md` | 평가 기준과 작업 경계 |
| `.claude/skills/freelance-opportunity-reporter/` | 외주 후보 수집 리포트 skill |
| `.claude/skills/freelance-proposal-preparer/` | 지원 제안서 준비 skill |
| `reports/` | 외주 공고 리포트와 원자료 |
| `data/runtime/` | 실행 중 임시 데이터 |

## 핵심 기준

- 리모트 가능성이 높아야 한다.
- 백엔드, API, 데이터, 인증, 관리자 화면, 업무자동화, AI/API 연동을 우선한다.
- 상주와 정기 출근이 필요한 공고는 제외한다.
- 단순 디자인, 퍼블리싱, 마크업 공고는 제외한다.
- 지원 전에는 사용자의 확인을 받는다.

## 사용 방법

외주 후보 리포트가 필요하면 `freelance-opportunity-reporter`를 사용한다.
지원 문안과 견적 정리가 필요하면 `freelance-proposal-preparer`를 사용한다.

리포트에는 다음을 포함한다.

- 플랫폼과 공고 URL
- 수집 시각
- 원격 가능성
- 기간과 예산
- 요구 기술
- 지원 가능성
- 주요 위험

## 검증

리포트 작성 후에는 다음을 확인한다.

- 상세 URL이 실제 공고로 연결되는지
- 원격 조건을 근거로 확인했는지
- 제외 기준에 걸리는 공고가 후보에 남지 않았는지
- 지원 전 사용자 확인이 필요한 항목을 분리했는지
