# fos-side

개인 사이드 프로젝트와 외주 기회 운영 실험을 관리하는 저장소다.

## 현재 내용

- `reports/`: 외주 공고 조사 리포트와 원자료
- `skills/`: Codex에서 재사용할 수 있는 스킬

## 핵심 스킬

- `freelance-opportunity-reporter`
  - 위시켓, 프리모아, 크몽, 숨고 등에서 외주 후보를 수집한다.
  - 리모트 가능성, 지원 가능성, 상품화 가능성을 분류한다.
  - 반복 운영 루프와 지원 전 체크리스트를 제공한다.

## 운영 원칙

- 리모트만 가능한 일을 우선한다.
- 상주, 반상주, 정기 출근, 현장 테스트가 필요한 공고는 제외한다.
- 목록 URL만으로 판단하지 않고 상세 URL과 근거 수준을 기록한다.
- 지원 전에는 사용자 확인을 거친다.
