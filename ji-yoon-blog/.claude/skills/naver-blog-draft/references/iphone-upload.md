# 아이폰에서 사진 올리기

## 왜 웹페이지인가

아이폰 단축어는 S3 가 요구하는 서명을 만들지 못한다.
서명에는 비밀 키로 HMAC 을 계산하는 단계가 있는데 단축어에 그 기능이 없다.

비밀 키를 페이지에 넣으면 그 페이지를 여는 사람이 저장소 전체를 열 수 있다.
그래서 스킬이 미리 서명한 업로드 주소만 페이지에 심는다.

주소 하나가 사진 한 장을 받고, 정해진 기간이 지나면 쓸 수 없다.
주소가 새어도 그 폴더에 사진을 넣는 것 말고는 할 수 없다.

## 쓰는 순서

1. 글로 쓸 곳에 다녀와서 사진을 찍는다.
2. 지융이 "사진 올릴 주소 줘"라고 말하면 스킬이 주소를 만들어 준다.
3. 아이폰 사파리에서 그 주소를 연다.
4. `사진 고르기`를 눌러 올릴 사진을 모두 고른다.
5. 한 장씩 올라가고, 끝나면 몇 장 올렸는지 보여준다.

## 파일 이름과 순서

파일은 `001.jpg` 부터 차례로 저장된다.
아이폰이 사진을 어떤 순서로 보내든 상관없다.
스킬이 사진의 촬영시각을 읽어 순서를 다시 세운다.

## HEIC 사진

아이폰이 HEIC 으로 찍어도 사파리가 파일을 고를 때 JPEG 로 바꿔 보낸다.
따로 설정할 것이 없다.

바뀌지 않고 올라가면 촬영시각을 읽지 못해 이름 순서로 세운다.
그때는 사진 순서를 지융에게 확인한다.

## 사진이 100장을 넘을 때

기본으로 자리를 100개 만든다.
포토로그처럼 사진이 많은 글은 자리를 늘려 주소를 다시 만든다.

```bash
python3 scripts/make_upload_page.py 2026-09-30-9월일상 --slots 300
```

## 주소가 만료됐을 때

기본 24시간이다.
만료된 뒤에 올리려 하면 사파리가 실패를 표시한다.
같은 폴더 이름으로 주소를 다시 만들면 된다.
이미 올린 사진은 그대로 있고, 이어서 올리면 앞 번호를 덮어쓸 수 있으므로
남은 장수를 확인하고 만든다.
