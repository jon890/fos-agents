# 지융로그 초안 만들기

사진에서 시작해 네이버 임시저장까지 간다.
발행은 하지 않는다.

## 먼저 읽을 것

글을 쓰기 전에 워크스페이스의 두 문서를 읽는다.

| 문서 | 무엇을 정하나 |
| --- | --- |
| `references/ji-yung-persona.md` | 인사, 문단을 끊는 방식, 부호 습관, 마무리, 태그 |
| `references/category-style-map.md` | 그 카테고리에서 반드시 담을 사실과 사진 순서 |

문체를 지어내지 않는다.
두 문서에 없는 판단이 필요하면 지융에게 묻는다.

## 준비

홈서버 접속 정보가 워크스페이스 `.env`에 있어야 한다.
`.env.example`이 필요한 항목을 보여준다.

```bash
python3 .claude/skills/naver-blog-draft/scripts/seaweed_s3.py list
```

설정이 없으면 어느 항목이 비었는지 알려준다.
그 상태로는 아래 단계를 진행할 수 없으므로 지융에게 값을 요청하고 멈춘다.

## 1. 사진 올릴 자리 만들기

지융이 아직 사진을 올리지 않았으면 업로드 페이지를 만들어 준다.

```bash
python3 .claude/skills/naver-blog-draft/scripts/make_upload_page.py 2026-09-04-순돌이곱창
```

폴더 이름은 `날짜-장소`로 짓는다.
장소는 상호명을 그대로 쓴다.

명령이 출력하는 주소를 지융에게 준다.
아이폰에서 그 주소를 열어 사진을 고르면 바로 올라간다.

이 주소는 기본 24시간 뒤에 만료된다.
지융이 나중에 올리겠다고 하면 `--hours`로 늘린다.
사진이 100장을 넘을 것 같으면 `--slots`를 올린다.

브라우저에 비밀 키를 두지 않는다.
서명한 업로드 주소만 페이지에 심으므로, 주소가 새어도 그 폴더에 사진을 넣는 것 말고는 할 수 없다.

## 2. 사진 읽기

```bash
python3 .claude/skills/naver-blog-draft/scripts/photo_set.py
```

인자 없이 부르면 올라와 있는 폴더 목록과 장수를 보여준다.

```bash
python3 .claude/skills/naver-blog-draft/scripts/photo_set.py \
  photos/2026-09-04-순돌이곱창/ --download ./drafts/순돌이곱창/photos
```

사진을 내려받고 순서를 잡는다.
순서는 촬영시각으로 세운다.
촬영시각이 없는 사진은 이름 순서로 뒤에 붙는다.

내려받은 사진을 실제로 본다.
무엇이 찍혔는지 보지 않고 본문을 쓰지 않는다.

## 3. 부족한 사실 묻기

사진만으로는 알 수 없는 것이 있다.
카테고리 모듈의 `반드시 담을 사실`을 보고 빠진 것을 추린 뒤 한 번에 묻는다.

맛집이면 대개 다음이 빠진다.

- 언제 갔는지와 얼마나 기다렸는지
- 주문한 메뉴와 가격
- 맛이 어땠는지, 아쉬웠던 점
- 주차와 정기휴무

지어내지 않는다.
지융이 모른다고 하면 그 대목을 본문에서 뺀다.

협찬이나 제공을 받았는지도 확인한다.
받았으면 형태에 맞는 고지 문구를 인사보다 앞에 둔다.

## 4. 초안 만들기

초안은 JSON으로 만든다.

```json
{
  "title": "불향 가득한 군산 곱창 맛집 순돌이곱창 메뉴, 웨이팅 후기",
  "category": "맛집로그",
  "tags": ["군산맛집", "군산곱창", "순돌이곱창웨이팅", "내돈내산"],
  "blocks": [
    {"type": "sticker", "emoji": "🍖"},
    {"type": "text", "lines": ["안녕하세요 지융입니다 😋", "오늘은 ..."]},
    {"type": "image", "path": "photos/001-001.jpg"},
    {"type": "map", "address": "전북특별자치도 군산시 우체통거리2길 43-9"}
  ]
}
```

`path`는 초안 파일이 있는 자리에서 본 상대 경로다.

블록 순서는 페르소나 문서의 기본 흐름을 따른다.
사진 한 장에 글 묶음 하나가 붙고, 그 묶음은 서너 줄이다.

제목은 후보를 셋 만들어 지융에게 고르게 한다.
검색어를 담되 지융이 실제로 쓰는 형태를 벗어나지 않는다.

## 5. 미리보기

```bash
python3 .claude/skills/naver-blog-draft/scripts/build_preview.py \
  drafts/순돌이곱창/draft.json --out drafts/순돌이곱창/preview.html
```

네이버 모바일 화면 폭으로 그린다.
사진을 찾지 못하면 그 자리를 표시하고 종료 코드 1로 끝난다.

미리보기를 지융에게 보여주고 확인을 받는다.
확인 없이 다음 단계로 가지 않는다.

## 6. 네이버 임시저장

브라우저 조작은 `~/.claude/scripts/browser-driver`로 한다.
첫 명령 전에 `browser-driver help`를 읽는다.

절차와 중단 조건은 `references/preview-automation.md`가 소유한다.
로그인 화면이나 보안 확인이 나오면 멈추고 지융에게 넘긴다.

넣는 순서는 제목, 본문, 사진, 태그다.
사진은 내려받은 파일을 편집기에 올린다.

끝나면 편집기 상태를 읽어 실제로 들어갔는지 확인한다.
확인한 것만 완료라고 말한다.

## 하지 않는 것

- 발행. 임시저장까지만 한다.
- 지융이 확인하지 않은 상태로 네이버에 넣기.
- 사진을 보지 않고 본문 쓰기.
- 가보지 않은 곳의 세부나 받지 않은 협찬 문구 넣기.
- 네이버 비밀번호, 인증번호, 쿠키를 요청하거나 저장하기.
