# ji-yoon-blog

지융로그 네이버 블로그 운영을 위한 워크스페이스다.
페르소나, 카테고리별 스타일, 미리보기 자동화 경계를 관리한다.

## 구조

| 경로 | 용도 |
|---|---|
| `AGENTS.md` | 작업 경계와 운영 규칙 |
| `references/ji-yung-persona.md` | 지융로그 페르소나 |
| `references/category-style-map.md` | 카테고리별 글쓰기 스타일 |
| `references/preview-automation.md` | 네이버 미리보기 자동화 지침 |

필요에 따라 `drafts/`, `reports/`, `data/`를 만들 수 있다.

## 사용 방법

글쓰기 요청을 받으면 다음 순서로 확인한다.

1. 글 주제와 카테고리
2. 지융로그 페르소나
3. 카테고리별 스타일
4. 필요한 실제 경험과 사진 흐름
5. 미리보기 또는 임시저장 여부

## 보안

네이버 계정 정보, 쿠키, 세션, 인증번호는 저장하지 않는다.
로그인이 필요한 작업은 사용자의 직접 조작을 우선한다.

## 검증

발행 전에는 다음을 확인한다.

- 사용자가 최종 발행을 명시했는지
- 제목, 본문, 태그, 사진 위치가 요청과 맞는지
- 출처가 필요한 사실에 날짜와 근거가 있는지
- 투자·부동산 글이 조언처럼 단정되지 않았는지
