# ji-yoon-blog 워크스페이스 지침

`ji-yoon-blog`는 지융로그 네이버 블로그 운영을 위한 독립 워크스페이스다.
이 파일은 작업 경계와 콘텐츠 라우팅만 담는다.

## 사용자

주 사용자는 지융이다.
지융의 콘텐츠 방향 지시를 우선한다.
비포스는 자동화와 워크스페이스 설정을 함께 관리한다.

## 범위

- 지융로그 페르소나 유지
- 카테고리별 글쓰기 스타일 관리
- 글감 추천, 제목 후보, 본문 초안, 태그, 사진 배치 가이드
- 내부 블로그 신호와 외부 트렌드 분석
- 네이버 블로그 미리보기 또는 임시저장 준비

## 읽기 순서

| 문서 | 책임 |
|---|---|
| `README.md` | 범위, 설정, 사용 방법 |
| `references/ji-yung-persona.md` | 지융로그 페르소나 |
| `references/category-style-map.md` | 카테고리별 글쓰기 모듈 |
| `references/preview-automation.md` | 네이버 미리보기 자동화 경계 |

## 보안

- 네이버 계정 정보, 비밀번호, 인증번호, 쿠키, 세션 값은 요청하거나 저장하지 않는다.
- 로그인이 필요하면 QR 로그인 또는 사용자의 직접 브라우저 로그인을 우선한다.
- 로그인, 보안 확인, 캡차, 기기 인증에서 막히면 중단하고 사용자 조작을 요청한다.
- 발행은 사용자가 명시적으로 요청하고 최종 확인한 경우에만 한다.

## 콘텐츠 원칙

- 실제 경험과 사진 흐름을 우선한다.
- 과한 광고 문구나 출처 없는 단정은 피한다.
- 주식과 아파트 글은 투자 조언처럼 단정하지 않는다.
- 날짜와 출처가 필요한 정보는 확인한 뒤 쓴다.

## 산출물

- 분석 리포트는 `reports/`가 있으면 그 아래에 둔다.
- 현재 저장소에는 `references/`가 핵심 관리 자산이다.
